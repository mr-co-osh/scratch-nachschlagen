EreignisseWann startet ein Skript?

  • Startet das Skript, wenn die grüne Flagge angeklickt wird.

  • Startet das Skript, wenn eine bestimmte Taste gedrückt wird.

  • Startet das Skript, wenn man die Figur anklickt.

  • Startet das Skript, wenn eine Nachricht ankommt.

  • Schickt eine Nachricht an alle Figuren und die Bühne.

  • Wie oben – wartet aber, bis alle Empfänger fertig sind.

SteuerungWarten, Wiederholen, Entscheiden, Klone

  • Macht eine Pause. Kommazahlen mit Punkt schreiben: 0.5

  • Wiederholt die Blöcke darin genau so oft wie angegeben.

  • Wiederholt die Blöcke darin für immer (bis Stopp).

  • Wiederholt, bis die Bedingung wahr ist.

  • Führt die Blöcke nur aus, wenn die Bedingung wahr ist.

  • Wahr → oberer Teil, falsch → unterer Teil (sonst).

  • Wartet, bis die Bedingung wahr wird.

  • Stoppt alle Skripte (oder nur dieses Skript).

  • Startet für jeden neuen Klon. Hier steht, was ein Klon tut.

  • Erzeugt eine Kopie (Klon) der Figur.

  • Löscht den Klon wieder – wichtig, sonst wird das Spiel langsam!

BewegungPosition und Richtung

  • Bewegt die Figur in ihre aktuelle Richtung.

  • Dreht die Figur im Uhrzeigersinn.

  • Springt an eine zufällige Stelle (oder zum Mauszeiger).

  • Springt an eine genaue Position im Koordinatensystem.

  • Bewegt sich langsam zu einer Position.

  • 90 = rechts, -90 = links, 0 = oben, 180 = unten.

  • Bewegt nach rechts (+) oder links (–).

  • Bewegt nach oben (+) oder unten (–).

  • Setzt die Höhe auf einen festen Wert (z. B. den Boden).

  • Dreht die Figur um, wenn sie den Rand berührt.

  • Figur schaut nur nach links oder rechts (steht nicht Kopf).

  • Aktuelle x-Position der Figur.

  • Aktuelle y-Position der Figur.

AussehenSprechen, Kostüme, Sichtbarkeit

  • Sprechblase für eine bestimmte Zeit.

  • Zeigt ein bestimmtes Kostüm der Figur.

  • Nächstes Kostüm – gut für Animationen.

  • Wechselt den Hintergrund.

  • Macht die Figur größer oder kleiner.

  • Verändert z. B. die Farbe der Figur.

  • Macht die Figur sichtbar.

  • Macht die Figur unsichtbar.

  • Holt die Figur nach vorne (vor andere Figuren).

KlangTöne und Geräusche

  • Spielt den Klang und wartet, bis er fertig ist.

  • Startet den Klang – das Skript läuft sofort weiter.

  • Beendet alle Klänge.

FühlenBerührungen, Tasten, Fragen, Stoppuhr

  • Wahr, wenn die Figur etwas berührt (Figur, Rand, Maus).

  • Wahr, wenn die Figur eine bestimmte Farbe berührt.

  • Wahr, solange die Taste gedrückt ist.

  • Stellt eine Frage und wartet auf eine Eingabe.

  • Enthält die letzte Eingabe.

  • Zählt die Sekunden seit dem Start oder Zurücksetzen.

  • Setzt die Stoppuhr auf 0.

OperatorenRechnen, Vergleichen, Verknüpfen

  • Rechnen: auch – , * (mal) und / (geteilt).

  • Liefert eine zufällige Zahl im Bereich.

  • Größer als (auch < kleiner als).

  • Gleich – vergleicht Zahlen oder Wörter.

  • Wahr, wenn BEIDE Bedingungen wahr sind.

  • Wahr, wenn MINDESTENS EINE Bedingung wahr ist.

  • Dreht wahr und falsch um.

  • Setzt Texte zusammen.

VariablenWerte speichern

  • Der aktuelle Wert der Variable.

  • Gibt der Variable einen festen Wert (z. B. beim Start).

  • Erhöht (+) oder verringert (–) den Wert.

  • Zeigt die Variable auf der Bühne.

  • Versteckt die Anzeige.

ListenViele Werte speichern

  • Hängt einen Eintrag hinten an die Liste an.

  • Löscht den Eintrag an einer Stelle.

  • Leert die ganze Liste.

  • Liefert den Eintrag an einer Stelle.

  • Wie viele Einträge hat die Liste?

  • Wahr, wenn der Eintrag in der Liste vorkommt.

Meine BlöckeEigene Blöcke bauen

  • Hier steht, was der eigene Block tut. „Größe“ ist eine Eingabe.

  • Ruft den eigenen Block mit einem Wert für die Eingabe auf.

MalstiftZeichnen (Erweiterung unten links hinzufügen)

  • Löscht alles Gezeichnete.

  • Ab jetzt zeichnet die Figur eine Linie, wenn sie sich bewegt.

  • Die Figur zeichnet nicht mehr.

  • Wählt die Farbe des Stifts.

  • Wählt die Dicke der Linie.

Das Koordinatensystem

Die Bühne ist 480 × 360 groß. Der Nullpunkt (0 | 0) liegt in der Mitte. Die genaue Position einer Figur siehst du unter der Bühne.

Code-Muster aus dem Basislager

Diese Muster tauchen in fast jedem Spiel auf. Nimm sie als Ausgangspunkt und passe sie an.

Startposition festlegen

Jede Figur sollte bei Spielstart an eine feste Stelle gehen – sonst steht sie dort, wo sie zuletzt war.

Steuerung mit Pfeiltasten

Die Abfrage in einer Schleife sorgt für flüssige Bewegung. Für oben und unten änderst du y statt x. „pralle vom Rand ab“ hält die Figur im Bild.

Einsammeln mit Zufallsposition

Die Bedingung wird in der Schleife immer wieder geprüft.

Gegner fliegt hin und her

„pralle vom Rand ab“ dreht die Figur am Rand um.

Punkte zählen und Nachricht senden

Erst die Variable bei Spielstart auf 0 setzen, dann bei jedem Treffer erhöhen.

Auf eine Nachricht reagieren

Jede Figur kann auf eine Nachricht reagieren – der Name muss genau gleich sein.

Countdown

Am besten auf der Bühne programmieren. „stoppe alles“ beendet das Spiel.

Fehlersuche – wenn es nicht klappt

Tippe auf eine Frage, um den Tipp zu sehen.

Passiert gar nichts?

Hat das Skript einen Startblock (z. B. „Wenn grüne Flagge angeklickt wird“)? Hängen alle Blöcke wirklich zusammen?

Reagiert etwas nur einmal?

Fehlt eine Schleife? Abfragen mit „falls“ müssen meist in „wiederhole fortlaufend“ stehen.

Falsche Figur?

Ist unten rechts die richtige Figur ausgewählt? Jede Figur hat ihre eigenen Skripte.

Komische Startwerte?

Werden alle Variablen, Positionen und Kostüme bei Spielstart zurückgesetzt?

Nachricht kommt nicht an?

Heißt die Nachricht beim Senden und beim Empfangen genau gleich?

Spiel wird langsam?

Werden Klone wieder gelöscht? Gibt es eine Schleife ohne „warte“, die ständig Klone erzeugt?

Figur bleibt hängen?

Gibt es eine Schleife, die nie endet („wiederhole bis“ mit einer Bedingung, die nie wahr wird)?

Immer noch ratlos?

Erkläre deinen Code Block für Block laut einer anderen Person. Oft findest du den Fehler dabei selbst!

Die goldene Regel: Ändere immer nur eine Sache und teste sofort. So weißt du genau, was den Unterschied gemacht hat.

Fachbegriffe

Hier findest du die wichtigsten Begriffe aus dem Kurs. Suche nach einem Begriff oder einer Erklärung.

Algorithmus
Eine genaue Schritt-für-Schritt-Anleitung, die ein Computer ausführen kann.
Skript
Eine Gruppe zusammenhängender Blöcke, die mit einem Startblock beginnt.
Ereignis
Etwas, das passiert (Klick, Tastendruck, Nachricht) und ein Skript startet.
Schleife
Wiederholt Blöcke – eine bestimmte Anzahl, für immer oder bis eine Bedingung erfüllt ist.
Bedingung
Eine Frage, die wahr oder falsch ist (z. B. „wird Rand berührt?“).
Verzweigung
„falls … dann … sonst“: Je nach Bedingung läuft ein anderer Teil des Codes.
Variable
Ein Speicherplatz mit Namen, dessen Wert sich ändern kann (Punkte, Zeit, Leben).
Liste
Eine Variable, die viele Werte der Reihe nach speichert.
Nachricht
Ein Signal, mit dem Figuren und Bühne sich gegenseitig Bescheid geben.
Klon
Eine Kopie einer Figur, die während des Spiels entsteht und wieder gelöscht werden kann.
Parameter / Eingabe
Ein Wert, den man einem eigenen Block mitgibt (z. B. die Größe eines Hauses).
Spielzustand
In welchem Abschnitt sich das Spiel gerade befindet (Start, Spiel, Game Over).
Debugging
Fehler im Code suchen und beheben.
Prototyp
Eine erste, einfache Version, mit der man eine Idee testet.
